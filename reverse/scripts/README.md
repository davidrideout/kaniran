# reverse/scripts

Tooling for the Common Lisp → Rust port. Treats the auto-generated `reverse/*.lisp/*.md` files as a dependency graph so you can refactor leaves first and walk up the call stack one wave at a time.

## Files

| File | Purpose |
| --- | --- |
| `introspect.lisp` | Original Lisp introspector — produces the `*.md` files (run inside SBCL). |
| `run-remote.sh` | Helper for invoking `introspect.lisp` against a remote ichiran image. |
| `build_graph.py` | Parses `reverse/**/*.md` into two CSVs. Run once after `introspect.lisp`. |
| `query.py` | Reads + mutates the CSVs to answer "what's a leaf?", "what's next?", etc. |
| `symbols.csv` | `fqn,name,package,file,line,kind,status,reason` — one row per defun/defmacro/defgeneric. `reason` is free-form text explaining off-the-books statuses (typically `skip`); empty for `pending`/`ported`. Sorted alphabetically by fqn for diff stability. |
| `edges.csv` | `caller_fqn,callee_fqn,resolved` — directed call edges. `resolved=0` means the callee is external/built-in and is ignored during traversal. |
| `PORT_PLAN.md` | **Canonical leaf-up port order**, generated by `query.py plan`. Deterministic across runs. Commit this; it's the agreed sequence for the Rust port. Re-generate after marking waves to see what's left. |

`fqn` is `<package>:<name>`, e.g. `ichiran/characters:test-word`. Use the bare name (`test-word`) wherever a command takes `<fqn>` — it auto-resolves when unambiguous.

## Setup

```sh
# (re)generate the CSVs from the .md files
python3 reverse/scripts/build_graph.py
```

Output:

```
symbols: 763 -> reverse/scripts/symbols.csv
edges:   2100 -> reverse/scripts/edges.csv
unresolved callees: 171 (external / built-in)
```

Re-run any time the `.md` files change. **Note:** rebuilding overwrites `symbols.csv`, which resets both `status` (→ `pending`) and `reason` (→ empty) for every row. Commit the CSV (or back it up) before regenerating if you have ported state or skip-reasons to preserve.

## query.py — syntax

```sh
python3 reverse/scripts/query.py <subcommand> [args]
```

### `leaves`

Symbols with no resolved callees and `status=pending`. Start your refactor here.

```sh
python3 reverse/scripts/query.py leaves
```

### `next`

Symbols whose every resolved callee already has `status=ported`. Run after `mark`-ing a wave to find what's now unblocked.

```sh
python3 reverse/scripts/query.py next
```

### `deps <fqn> [--deep]`

What `<fqn>` calls. Without `--deep`: direct callees only. With `--deep`: transitive closure.

```sh
python3 reverse/scripts/query.py deps join-branches
python3 reverse/scripts/query.py deps ichiran/dict:find-word --deep
```

### `dependents <fqn> [--deep]`

What calls `<fqn>` (reverse direction).

```sh
python3 reverse/scripts/query.py dependents kr-canonical
python3 reverse/scripts/query.py dependents kr-canonical --deep
```

### `layers`

Topological layering: layer 0 = leaves, layer N = `1 + max(layer of resolved callees)`. Symbols in cycles get layer `-1`. Note that the `-1` bucket flags symbols *reachable from* any cycle, not just true cycle members — use `plan` for an accurate SCC view.

```sh
python3 reverse/scripts/query.py layers
```

### `plan`

The full port plan as a topologically-sorted list. Each entry is one symbol unless it's part of a strongly-connected component (mutual recursion), in which case the whole SCC is listed as a single wave to be ported as a unit. Computed via Tarjan's algorithm, so it identifies *true* cycles only.

```sh
# stdout
python3 reverse/scripts/query.py plan

# write to a file (markdown)
python3 reverse/scripts/query.py plan --out reverse/scripts/PORT_PLAN.md

# narrow scope (default already excludes test+maintenance)
python3 reverse/scripts/query.py plan --skip-packages ichiran/test,ichiran/maintenance,ichiran/cli

# only what's left to port
python3 reverse/scripts/query.py plan --include-status pending
```

Output format:

```
   1. `ichiran/characters:to-normal-char`  — fn, characters.lisp:242
   2. `ichiran/characters:as-hiragana`  — fn, characters.lisp:282
 ...
 115. **CYCLE (2 symbols — port together)**
         - `ichiran/dict:calc-score`  — fn, dict.lisp:775
         - `ichiran/dict:kanji-break-penalty`  — fn, dict.lisp:702
 116. `ichiran/dict:gen-score`  — fn, dict.lisp:985
```

Wave numbers can shift if you re-run `build_graph.py` — they're guidance, not stable IDs. Use the FQN.

### `mark <fqn>... [--status STATUS] [--reason "text"]`

Sets the `status` column for one or more symbols and writes `symbols.csv` back. Default status is `ported`. Use any string — `next`, `wip`, `skip`, etc. work fine; only `ported` is meaningful to the `next` command.

`--reason` records a free-form note in the `reason` column. Recommended for `skip` and any other off-the-books status, so that the rationale survives in the CSV and shows up in the PORT_PLAN.md badge. Omit `--reason` to leave any existing reason untouched (so re-marking a row's status doesn't silently drop its prior justification).

```sh
python3 reverse/scripts/query.py mark kr-branch kr-canonical kr-pattern kr-rest
python3 reverse/scripts/query.py mark find-word --status wip
python3 reverse/scripts/query.py mark kr-canonical --status pending   # un-port
python3 reverse/scripts/query.py mark some-fqn --status skip --reason "no Rust counterpart needed"
```

### `stats`

Overall counts plus a per-package breakdown by status.

```sh
python3 reverse/scripts/query.py stats
```

## Typical workflow

```sh
# 1. Generate the graph (once, or after introspect.lisp re-runs)
python3 reverse/scripts/build_graph.py

# 2. Find leaves and port them in Rust
python3 reverse/scripts/query.py leaves

# 3. Mark the wave as done
python3 reverse/scripts/query.py mark to-normal-char as-hiragana as-katakana ...

# 4. See what's now unblocked
python3 reverse/scripts/query.py next

# 5. Repeat from step 3.
```

## Notes

- Unresolved callees (171 currently — CL built-ins, postmodern, cl-ppcre, etc.) are recorded in `edges.csv` with `resolved=0` but are **ignored** by `leaves`, `next`, `deps`, `dependents`, and `layers`. They don't block porting.
- A symbol with only unresolved callees counts as a leaf.
- Cycles exist (mostly mutually-recursive parsers in `dict.lisp`); `layers` flags them so they don't crash the topological sort.
